# Old Experiment Packages

These packages are no longer part of the current live collector/scorer/Telegram
workflow. They remain here so their code and results can still be inspected or
re-run intentionally.

- `basic_plus_visual`: single-stage catalog plus image/DINO experiment.
- `basic_5_voting`: offline voting experiment over basic-5 models.
- `basic_5_stacking`: offline stacking experiment over basic-5 models.
- `global_model`: offline global sold-status model experiment.

Old import paths under `scripts/experiments/<package>` remain as compatibility
wrappers during the transition.
